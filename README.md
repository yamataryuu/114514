# 像素割草 · 十波幸存者（静态网站版）

一个纯前端的像素风割草游戏：**没有后端、没有数据库、没有构建步骤、没有第三方依赖**。
把下面 6 个文件放进任意静态网站根目录，用浏览器访问网址就能玩；手机、平板、电脑都支持。

```
site/
├── index.html              ← 游戏本体（HTML + CSS + JS 全在这里）
├── manifest.webmanifest    ← PWA 清单：可「添加到主屏幕」像 App 一样全屏打开
├── sw.js                   ← Service Worker：首次访问后断网也能玩
├── icon-192.png            ← 桌面/主屏幕图标
├── icon-512.png            ← 桌面/主屏幕图标（大）
└── README.md               ← 本文件
```

---

## 一、本地先跑起来（30 秒）

```bash
cd site
python3 -m http.server 8080
```

浏览器打开 <http://localhost:8080> 即可。
> 不要直接双击 `index.html` 玩「网站版」：本地 `file://` 下 Service Worker 会被浏览器禁用（游戏本身仍能玩，只是没有离线缓存）。想直接双击玩，用同目录下的单文件版 HTML。

## 二、拿到一个公网网址（任选一种，都免费）

### 方案 A：Netlify Drop（最快，不用注册也能上传）
1. 打开 <https://app.netlify.com/drop>
2. 把整个 `site` 文件夹**拖进网页里的虚线框**
3. 立刻得到 `https://xxxxxx.netlify.app`，手机直接打开就能玩
   （注册账号可保留这个网址；不注册也能用一段时间）

### 方案 B：GitHub Pages（永久免费）
1. 新建仓库，例如 `pixel-survivors`
2. 把 `site` 里的 6 个文件上传到仓库**根目录**
3. 仓库 → `Settings` → `Pages` → `Deploy from a branch` → 选 `main` / `root` → Save
4. 约 1 分钟后访问 `https://你的用户名.github.io/pixel-survivors/`

### 方案 C：Vercel / Cloudflare Pages
注册后 `New Project` → 直接拖入 `site` 文件夹（或导入上面那个 GitHub 仓库）→ 一键部署，自动分配 HTTPS 网址。

### 方案 D：自己的服务器 / 对象存储
把 6 个文件放到 Nginx / Apache / 腾讯云 COS 静态网站 / 阿里云 OSS 的站点根目录即可。
若服务器不认识 `.webmanifest`，在 Nginx 加一行（不加也不影响游戏，只是 PWA 安装提示可能不出现）：

```nginx
types { application/manifest+json webmanifest; }
```

> Service Worker 只在 **HTTPS 或 localhost** 下生效。以上方案除本地预览外都是 HTTPS，所以离线功能可直接用。

## 三、怎么玩

| 平台 | 移动 | 开火 | 其他 |
|---|---|---|---|
| 电脑 | `W A S D` / 方向键 | 自动瞄准最近敌人 | `P` 暂停、`M` 静音、`空格` 开始/重开、`1 2 3` 选强化 |
| 手机 | **左下角虚拟摇杆**（轻推慢走，推满快跑） | 自动 | 屏幕下方按钮：暂停 / 音效 / 全屏；升级时**点卡片** |

- 红色追击怪贴身扣血；紫色弹幕怪远程扇形开火，**碰到它们的弹幕也会扣血**，命中后有 0.85 秒无敌帧。
- 捡青色经验宝石升级，三选一强化（伤害、射速、多重射击、移速、护甲、穿透、磁力、回血、弹速）。
- 共 10 波：1–2 波纯追击，第 3 波起加入弹幕怪，数量与强度逐波上升，波间回 1 血。
- 第 10 波 Boss「弹幕领主」：1250 血，环形弹幕每轮**固定留约 65° 安全缺口**且缺口会旋转，穿插螺旋弹，阶段之间有 1.5 秒完全停火窗口；敌弹 5.5 秒消失、上限 300 发，Boss 与玩家保持距离——密集但永远有路可走。

**手机上建议横屏**；竖屏也能玩，只是画面偏小。用手机浏览器打开网址后，菜单里选「添加到主屏幕」，就能像 App 一样全屏启动，并且**断网也能玩**。

## 四、调试参数（网址后面加）

| 参数 | 作用 |
|---|---|
| `?wave=10` | 直接从 Boss 波开始 |
| `?fast=1` | 加速刷怪，快速验收 10 波流程 |
| `?god=1` | 无敌，练习 Boss 走位 |

例：`https://你的网址/?wave=10&fast=1&god=1`

## 五、更新版本

改完 `index.html` 后，把 `sw.js` 第一行的缓存名换一个新的（例如 `pixel-survivors-v2`），
用户下次打开就会拉到新版本；不换名字的话老用户会一直用缓存里的旧版。

## 六、技术说明

- 渲染：480×300 低分辨率离屏 Canvas 放大 2 倍 → 纯正像素颗粒感；HUD 用 960×600 清晰层绘制。
- 自适应：`canvas` 宽度取 `min(96vw, 960px, (100dvh - 118px) * 1.6)`，横竖屏与安全区（刘海屏）都做了适配。
- 输入：Pointer Events 统一鼠标/触摸，`setPointerCapture` 保证手指滑出画布也不丢摇杆；`touch-action: none` 防止误滚动、误缩放。
- 音效：WebAudio 实时合成，无音频文件；可一键静音。
- 兼容性：Chrome / Edge / Safari / Firefox 现代版本，无需任何 polyfill。
